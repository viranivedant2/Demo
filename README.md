# Interactive Personal Data Collector

### A Simple Python CLI Tool for Data Collection and Inspection

## 📌 About Project

The **Interactive Personal Data Collector** is a beginner-friendly Python command-line interface (CLI) application designed to collect user input, perform basic data processing, and inspect Python data structures.

It gathers personal details such as name, age, height, and favorite number, displays their dynamic data types alongside memory address allocations using Python's built-in `id()` function, and automatically calculates the user's approximate birth year.

## ✨ Features

* **Interactive User Input:** Collects various data types including strings, integers, and floating-point numbers.
* **Data Type & Memory Inspection:** Displays the data type (`type()`) and memory address (`id()`) for each collected variable.
* **Calculated Metrics:** Automatically calculates and displays the user's estimated birth year based on their age.
* **Clean Terminal Interface:** Well-formatted terminal outputs using f-strings and formatted line breaks.

## 🛠️ Technologies Used

* **Language:** Python 3.x
* **Core Concepts:**
  * Variables & Data Types (`str`, `int`, `float`)
  * Type Casting (`int()`, `float()`)
  * String Formatting (f-strings)
  * Built-in Functions (`print()`, `input()`, `type()`, `id()`)

## 🚀 How to Run

1. **Prerequisites:**
   Ensure you have Python installed on your system. You can check by running:
   ```bash
   python --version
   ```

2. **Clone or Download the Repository:**
   Save the code file (`main.py`) to your local machine.

3. **Run the Script:**
   Open your terminal or command prompt, navigate to the directory containing `main.py`, and run:
   ```bash
   python main.py
   ```

4. **Interact with the Program:**
   Follow the on-screen prompts to enter your information and view the generated report.
